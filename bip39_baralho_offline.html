Regra Matemática

a = índice da 1ª carta (0-51)
b = índice da 2ª carta (0-51, b ≠ a)
b' = b se b < a, senão b - 1
N = 51×a + b'
Se N ≤ 2047: palavra = wordlist[N]
Se N ≥ 2048: DESCARTAR (embaralhe e repita)
